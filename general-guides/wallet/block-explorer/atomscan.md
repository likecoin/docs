# ATOMScan

## 如何在 ATOMScan 查看錢包明細

### 步驟一

到 Ping.pub 網站，或直接到 [https://ping.pub/likecoin](https://ping.pub/likecoin)。

在搜尋欄輸入錢包地址。

### 步驟二

成功查看錢包明細。
