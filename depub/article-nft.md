# 查看文章 Writing NFT

{% include "../.gitbook/includes/warning.md" %}

以下是在 Liker Land 查看你的 Writing NFT 的步驟：

前往 [Liker Land](https://liker.land/) 登入你的帳戶。登入後，點擊上角的頭像，選擇「我的書架」。

在書架頁面，點擊「篩選」按鈕，然後選擇「文章」，即可查看所有Writing NFT。
