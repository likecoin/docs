# 設定 NFT 電子書套裝

NFT 電子書套裝結合多本 NFT 電子書成為套裝銷售，適合系列叢書或各種促銷之用。

到 [LikeCoin NFT Book Press](https://likecoin.github.io/nft-book-press/) 網站，點「Manage Book Collection」，進入網站後按右上角「Connect Wallet」連結 Keplr。

## NFT Book Collections

點「New Collection」設定新的 NFT 電子書套裝。

<figure><img src="../../.gitbook/assets/Manage Book Collection 1.png" alt=""><figcaption><p>NFT Book Collections</p></figcaption></figure>

## Collection Info

* Books in Collection - 輸入 NFT 電子書的 Class ID，再點「Add」
* Total number of packages available for sale - 可供銷售的 NFT 電子書套裝數量

其餘步驟與上架 NFT 電子書相同，設定完成後點「Submit」即可設定 NFT 電子書套裝。
