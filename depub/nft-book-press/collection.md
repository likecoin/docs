# 設定電子書套裝

電子書套裝結合多本電子書成為套裝銷售，適合系列叢書或各種促銷之用。

到 [LikeCoin NFT Book Press](https://likecoin.github.io/nft-book-press/) 網站，進入網站後按右上角「Connect Wallet」連結錢包，再點「Manage Book Collection」，

### NFT Book Collections

點「New Collection」設定新的電子書套裝。

<figure><img src="../../.gitbook/assets/Manage Book Collection 1.png" alt=""><figcaption><p>NFT Book Collections</p></figcaption></figure>

### Collection Info

* Books in Collection - 輸入電子書的 Class ID，再點「Add」
* Total number of packages available for sale - 可供銷售的電子書套裝數量

其餘步驟與上架電子書相同，設定完成後點「Submit」即可設定電子書套裝。
