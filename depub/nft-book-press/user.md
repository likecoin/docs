# 用戶設定

到 [LikeCoin NFT Book Press](https://likecoin.github.io/nft-book-press/) 網站，進入網站後按左下角「Sign in」連結錢包，再點「[User Setting](https://likecoin.github.io/nft-book-press/nft-book-store/user)」。

仍未設定 Stripe 帳戶將顯示「No」。建議逐一完成 Book Affiliation Program 及 Stripe Connect 設定以參與推廣聯盟計劃及收取售書貨款。

<figure><img src="../../.gitbook/assets/Manage Stripe Account 1.png" alt=""><figcaption><p>User Setting</p></figcaption></figure>

點「**Setup your ID**」將開始註冊 Liker ID 及驗證電郵流程，詳見：

{% endcontent-ref %}

亦可修改頭像及顯示名稱：

完成設定後顯示 Affiliation channel ID。

<figure><img src="../../.gitbook/assets/Manage Stripe Account 11.png" alt=""><figcaption><p>Affiliation channel ID</p></figcaption></figure>

在任何電子書網址連結附加 `?from=@[Liker ID]`，即可從書籍銷售中獲得佣金。舉例：

* Liker ID 是 `ckxpress`
* NFT的連結是 https://liker.land/zh-Hant/nft/class/likenft19symzw3xmh42gukzts858wf6rsdkn6e4jtc9wp8jh4kphfmffy5s6acyxg
* 專屬連結就是 https://liker.land/zh-Hant/nft/class/likenft19symzw3xmh42gukzts858wf6rsdkn6e4jtc9wp8jh4kphfmffy5s6acyxg?from=@ckxpress

### Stripe Connect Status

點「**Setup your ID**」開始設定 Stripe 帳戶。

系統將跳轉至 Stripe 網站。填寫你的電郵 ( Email )及流動電話號碼 ( Mobile number )，點「Continue」。

<figure><img src="../../.gitbook/assets/Manage Stripe Account 2.png" alt=""><figcaption><p>填寫電郵及電話號碼</p></figcaption></figure>

你的電話會收到驗證碼 ( verification code )，把它填進去。

<figure><img src="../../.gitbook/assets/Manage Stripe Account 3.png" alt=""><figcaption><p>輸入驗驗碼</p></figcaption></figure>

在 Tell us about your business 頁面填寫所在國家 ( Country ) 及產業屬性 ( Type of business )，點「Continue」。

<figure><img src="../../.gitbook/assets/Manage Stripe Account 4.png" alt=""><figcaption><p>填寫所在國家及產業屬性</p></figcaption></figure>

在 Verify your personal details 頁面輸入名字 ( First Name )、姓氏 ( First Name ) 及出生日期 ( Date of birth )，點「Continue」。

<figure><img src="../../.gitbook/assets/Manage Stripe Account 5.png" alt=""><figcaption><p>輸入名字、姓氏及出生日期</p></figcaption></figure>

點銀行帳戶 ( Bank Account ) 設定你的i帳戶擁有者姓名 ( Account holder name )、選擇銀行 ( Choose your bank )、選擇分行 ( Choose your branch ) 及輸入你的帳戶號碼 ( Account Number ) 再點「Save」。

<figure><img src="../../.gitbook/assets/Manage Stripe Account 6.png" alt=""><figcaption><p>填寫銀行帳戶資料</p></figcaption></figure>

如選擇密碼貨幣提現、選擇加密錢包 ( Crypto wallet )，再選擇常種 ( Currency ) 及網絡 ( Network ) 及輸入錢包地址後 ( wallet address ) 再點「Save」。

<figure><img src="../../.gitbook/assets/Manage Stripe Account 7.png" alt=""><figcaption><p>填寫密碼貨幣錢包資料</p></figcaption></figure>

在 Review and submit 頁面查看輸入資料是否正確，完成後再點「Agree and submit」。

<figure><img src="../../.gitbook/assets/Manage Stripe Account 8.png" alt=""><figcaption><p>資料無誤點「Agree and submit」</p></figcaption></figure>

Stripe 審批完成後 Setup Completed 將轉為「Yes」。

<figure><img src="../../.gitbook/assets/Manage Stripe Account 9.png" alt=""><figcaption><p>Stripe 審批完成</p></figcaption></figure>

你可以隨時點「**Login to Stripe account**」查看或修改資料。

<figure><img src="../../.gitbook/assets/Manage Stripe Account 19.png" alt=""><figcaption><p>點「Login to Stripe account」查看或修改資料</p></figcaption></figure>

### User Setting

User Setting 顯示 Liker ID 所設置的電郵，Email Notification Settings 預設為 Receive email notifications about commissions 即收關於佣金的電郵。如不想收取該等電郵可把它關掉再點「**Update**」更新。

<figure><img src="../../.gitbook/assets/Manage Stripe Account 12.png" alt=""><figcaption><p>User Setting</p></figcaption></figure>
