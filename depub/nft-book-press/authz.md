# 管理 Authz 授權

到 [LikeCoin NFT Book Press](https://likecoin.github.io/nft-book-press/) 網站，進入網站後按左下角「Sign in」連結錢包，再點「[NFT Authz Grants](https://likecoin-nft-book-press-testnet.netlify.app/authz)」。

### Send NFT Authz Grants Management Page

授予其他錢包發送 NFT 的授權許可（即 NFT Authz 權限）即容許他們代表你發送你所擁有的任何 NFT，不限於出版的 NFT 書籍或新發行的 Writing NFT。請謹慎使用，並且只授權給你信任的人。

* 在 Current Grants 的錢包清單顯示 Wallet 錢包地址及 Expiration 即該錢包的授權到期日。點「**Renew**」可更新授權，點「**Revoke**」即撒消授權。
* 在 Grant new send NFT Authz 的欄位輸入錢包地址再點「**Submit**」可創建新的授權。
