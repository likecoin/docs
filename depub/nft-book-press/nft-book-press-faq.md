# 上架 Liker Land NFT 電子書的常見問題

[Book Press](https://likecoin.github.io/nft-book-press/) 為 [Liker Land](https://liker.land/zh-Hant) 提供的提供的自助上架服務。我們提供作者 / 出版者上架販售，讓作者自行出版，也可以作為出版社擔任發行的角色，因此您除了是作者外，亦是您作品的出版者（出版社）Liker Land 則為販售您作品的電子書服務，不佔任何作品版權，也不會要求分成作品於其他平台銷售所得的利潤。\
\
如果您還有任何問題，歡迎您來信 [publish@liker.land](mailto:publish@liker.land) 與我們聯絡。

## 電子書權利歸屬

Liker Land 只負責將您的作品代理經銷至我們的平台，電子書的出版權及著作權仍歸作者（或合法代理人）所擁有，Liker Land 是經您授權同意後轉製並代為發佈銷售。

## 電子書平台服務費

電子書平台會收取一定比例的平台服務費：

一般為實售價之 35%。當中的 30% 為銷售通路佣金\*，5% 則為平台收費。

\*經 Liker Land 網站銷售的佣金。Liker Land 建議劃一讓任何渠道，例如書店、網站、或 KOL 等抽成 30% 利潤，鼓勵更多人協助銷售。 Liker Land 提供工具讓作者生成不同的網址連結，發予不同的渠道，經特定連結達成的交易會記錄渠道資料，讓作者可把收入分成給渠道。 作者有責任確保渠道使用正確的連結賣書。Liker Land 會把所有沒使用渠道連結達成的交易歸類為經 Liker Land 銷售。 &#x20;

## 上架費用 （Network Fee）

視乎 file size 而定的，還有匯率因素，所以很難推算。最實際是如果你已經有一個檔案就可以直接用系統去估算。

比方說周作人《雨天的書》，儲存費 2.7 MB - 0.12 USD （只收一次）

而印 1 本電子書大概 - 0.005 USD （計算印幾本)

## 電子書版稅計算

書籍實際銷售金額扣除平台服務費即為您可獲得的電子書版稅。

電子書： 書籍實售價 x 35% + 書籍實售價的 4.4%（[Stripe 信用卡收費](https://stripe.com/en-hk/pricing)） + $0.30

例：若您的書在 Liker Land 上架，售價 100 元。每銷售一本，於 Liker Land 可獲得的權利金為：100 x 35% + (100 x 4.4% + 0.3) = 39.7 元/本

## 關於上架 （[詳細教學](./)）

### 是否提供製作 EPUB 檔服務？

基本服務只包括上架服務。EPUB 檔，封面設計，編輯，排版，策展等額外服務，歡迎您來信 [publish@liker.land](mailto:publish@liker.land) 與我們聯絡。

### 定價與售價

您可依照個人意願與需求設定書籍的定價與實售價。提醒您，實售價只能等於或小於定價，有價商品的最低實售價是 $0.99 美元。

### 免費

若您希望讓讀者免費領取您的書籍，可將該書價格設定為 0 元。我們也支援「打賞」功能，讓讀者可以額外打賞自訂金額，進一步支持作者。

### 價格修改

書籍上架後，你可以自由更改價格或是進行優惠促銷，生效日期皆為即時自動更新。

## 上架流程

### 書封

完整的 EPUB 檔即包含書封，所以您無須另外上傳。如果您是上傳非 EPUB 格式之檔案需另外上傳書封。PDF 檔案，則要獨立上傳一個圖檔作書封。

### 書籍名稱、作者、分類

書籍名稱、作者、標籤，是讀者認識作品的第一步，請務必正確填寫。

### 關鍵字

好的關鍵字設定可以幫助讀者搜尋相關主題時帶出您的作品，增加作品曝光的機會。不建議您將與作品無關的詞彙放在關鍵字中，容易造成反效果。

### 出版社 / 作者專屬網址

當該出版社 / 作者的第一本出版品後，該出版社即有擁專屬網址，您可以分享該網址宣傳書籍。
